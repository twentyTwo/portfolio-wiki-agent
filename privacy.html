Privacy Policy

Portfolio Wiki Agent, last updated 10 November 2026.

Portfolio Wiki Agent is a personal tool used only by its developer, Noor Alam Shuvo. It is not offered to the public.

What it accesses

With the developer's consent, the app uses the Google Tasks scope (https://www.googleapis.com/auth/tasks) to create, read, update and delete tasks in the developer's own Google Tasks account.

How data is used and stored

  • Task data is used only to show and manage the developer's task list.
  • Access tokens are stored only on the developer's own devices or private environments.
  • No data is sold, shared with third parties, used for advertising, or used to train AI models.
  • The app uses no analytics or tracking.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
